# UniMate email templates

Dark, app-style emails. Paste each file into Supabase → Authentication → Emails.

- `confirm-signup.html` → **Confirm sign up** (Authentication → Emails → Confirm sign up). Subject: Verify your email to get started with UniMate
- `invite-user.html` → **Invite user** (Authentication → Emails → Invite user). Subject: You're invited to UniMate
- `magic-link.html` → **Magic link or OTP** (Authentication → Emails → Magic link). Subject: Your UniMate sign-in link
- `change-email.html` → **Change email address** (Authentication → Emails → Change email address). Subject: Confirm your new email for UniMate
- `reset-password.html` → **Reset password** (Authentication → Emails → Reset password). Subject: Reset your UniMate password
- `reauthentication.html` → **Reauthentication** (Authentication → Emails → Reauthentication). Subject: Your UniMate security code
- `password-changed.html` → **Password changed** (Authentication → Emails → Notifications → Password changed). Subject: Your UniMate password was changed
- `email-changed.html` → **Email address changed** (Authentication → Emails → Notifications → Email address changed). Subject: The email on your UniMate account was changed
- `phone-changed.html` → **Phone number changed** (Authentication → Emails → Notifications → Phone number changed). Subject: The phone number on your UniMate account was changed
- `identity-linked.html` → **Sign-in method linked** (Authentication → Emails → Notifications → Sign-in method linked). Subject: A new sign-in method was added to UniMate
- `identity-unlinked.html` → **Sign-in method removed** (Authentication → Emails → Notifications → Sign-in method removed). Subject: A sign-in method was removed from UniMate
- `mfa-added.html` → **MFA method added** (Authentication → Emails → Notifications → MFA method added). Subject: Two-step sign-in was added to UniMate
- `mfa-removed.html` → **MFA method removed** (Authentication → Emails → Notifications → MFA method removed). Subject: Two-step sign-in was removed from UniMate
